Offbeat

AI Digital Wellbeing Coach

AI-powered focus coaching for people who want healthier digital habits without blunt, punitive blockers.

Overview

Offbeat is a premium Android app built in Flutter to help users regain control of their attention through adaptive digital wellbeing coaching. Instead of locking users out with fixed limits, it learns their real usage patterns and responds with context-aware, non-punitive insights that help them understand when they are compulsively scrolling versus intentionally using their devices.

Key Features

  • Addiction Score (0–100) for each app based on compulsive patterns and frequency, not just raw screen time.
  • Focus Shield that closes common bypass routes as soon as usage exceeds a user-defined threshold.
  • Notification muting, focus modes, hourly heatmaps, AI Weekly Insights, and daily AI Pulse coaching.
  • Dopamine Detox streaks, urge journaling, and privacy-first local data tracking with offline-only AI insights.

Tech Stack

Flutter / Dart, Kotlin platform channels, UsageStatsManager, NotificationListenerService, Isar local database, Flutter CustomPainter, BackdropFilter, and Google AdMob.

Challenges & Highlights

The most technically interesting part of the build was the Android-native enforcement layer and the custom glassmorphism UI system. I implemented real-time app blocking with platform channels, managed sensitive Android permissions carefully, and built the interface with no third-party UI kit using Flutter's CustomPainter and BackdropFilter to achieve a premium liquid-glass visual language that feels modern and intentional while remaining performant.

CLIENT PROJECT

PromptGuard

LLM Injection Defense

An AI-powered security firewall that protects enterprise LLM deployments from prompt injection and data leakage.

My Role

Solo full-stack developer — built the entire backend, ML integration, and Flutter mobile app end-to-end, based on a client’s SRS/SDS requirements and UI prototype.

Key Features

  • Real-time prompt injection and jailbreak detection using a pretrained DeBERTa-v3 transformer classifier.
  • Sensitive data detection for PII, API keys, credit cards, and credentials with configurable masking or blocking rules.
  • Fail-closed pipeline, live admin dashboard, audit logging with SHA-256 hashing, and AI-driven alert triage.
  • RBAC, policy tuning, CSV compliance exports, and system health monitoring for enterprise deployments.

Tech Stack

Flutter / Dart, Python, FastAPI, SQLAlchemy, PostgreSQL, Hugging Face Transformers, PyTorch, JWT, bcrypt, and Role-Based Access Control.

Challenges & Highlights

One of the hardest parts was integrating a real pretrained transformer model for semantic attack detection and building a policy-driven engine where admin-configured rules affect the live security pipeline. I also solved cross-platform networking and deployment challenges across Android emulator, Chrome web, and physical devices, making the platform resilient and client-ready.
